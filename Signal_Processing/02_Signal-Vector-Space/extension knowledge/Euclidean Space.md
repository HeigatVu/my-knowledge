# Real 2-Dimensional Space ($\mathbb{R}^2$)

In $\mathbb{R}^2$, an element (or vector) is typically represented as a column vector. This can be compactly written using the transpose operator:

$$\mathbb{R}^2 : \quad \mathbf{x} = \begin{bmatrix} x_0 & x_1 \end{bmatrix}^T$$
![[Euclidean Space_R2-graphic.png]]
### Breakdown
* $\mathbf{x}$: The bold symbol denotes a vector.
* $x_0, x_1$: The individual components or coordinates within the vector.
* $(\dots)^T$: The [[Transpose]] operator, which flips a row vector into a column vector:

$$\mathbf{x} = \begin{bmatrix} x_0 \\ x_1 \end{bmatrix}$$

# Real 3-Dimensional Space ($\mathbb{R}^3$)

In $\mathbb{R}^3$, an element (or vector) contains three components, representing a coordinate or direction in three-dimensional space. It is written compactly using the transpose operator:

$$\mathbb{R}^3 : \quad \mathbf{x} = \begin{bmatrix} x_0 & x_1 & x_2 \end{bmatrix}^T$$
![[Euclidean Space_R3-graphic.png]]
### Breakdown
* $\mathbf{x}$: The bold symbol denotes a vector in 3D space.
* $x_0, x_1, x_2$: The individual components corresponding to the axes (often thought of as the $x$, $y$, and $z$ coordinates).
* $(\dots)^T$: The [[Transpose]] operator, showing that it represents the following column vector:

$$\mathbf{x} = \begin{bmatrix} x_0 \\ x_1 \\ x_2 \end{bmatrix}$$
